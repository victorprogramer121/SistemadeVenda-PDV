# SistemadeVenda-PDV

Sistema voltado a venda de livros online. 
Nos baseamos em sites grandes de venda, como o Mercado Livre, Amazon e Shoppe
Nosso intuito com esse projeto, é estar cada vez mais habituado com as linguagens utilizadas e aprender um pouco mais a programar.

## Linguagens utilizadas:
Frontend:
- HTML
- CSS
- JavaScript
- Angular
  
Backend:
- TypeScript
- Node

Banco de Dados:
- PostgreeSQL
